## Razarsa v1.0.0 🐉

Rilis pertama Razarsa: satu aplikasi Android untuk mengatur keuangan dan kegiatan harianmu. Semua data tersimpan **di HP**, tanpa akun online dan tanpa server.

### ✨ Fitur
**💰 Keuangan**
- Catat pemasukan dan pengeluaran, **Catat Cepat** sekali tap
- Laporan, anggaran bulanan dan per kategori, target tabungan
- Transaksi berulang dan pengingat tagihan
- Kategori khas Indonesia, bisa buat sendiri

**✅ Produktif**
- Tugas dan kalender dengan pengingat
- Catatan dengan folder, sematan, dan kunci PIN

**Untuk semua mode**
- Dua mode (Keuangan dan Produktif), tema terang/gelap, Indonesia/English
- Profil dengan level, avatar, bingkai, sampul, lencana, dan kartu bagikan
- Kunci PIN dan sidik jari, catatan terkunci terenkripsi
- Backup berkata sandi, pulihkan, dan ekspor CSV

### ⚠️ Perlu diketahui
- Simpan backup berkata sandi. Kalau PIN atau kata sandi backup lupa, tidak bisa dipulihkan.
- Judul catatan terkunci tetap terlihat; isinya terenkripsi.
- Nama paket aplikasi ini `com.razarsa`, jadi Android menganggapnya aplikasi baru. Kalau kamu pernah memakai versi sebelumnya, buat backup di sana lalu pulihkan di sini.

### 📲 Pilih APK
- **`-arm64.apk`**: untuk hampir semua HP Android modern ← **pilih ini**
- **`-universal.apk`**: untuk semua HP
