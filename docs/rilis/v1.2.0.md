## Razarsa v1.2.0 🛠️

**Fix bug dan lain-lain.** Rilis ini fokus membuat datamu lebih aman dan aplikasi lebih rapi.

### 🔒 Keamanan
- **PIN lebih kuat.** PIN kini disimpan dengan pengacakan berlapis (PBKDF2 + salt acak per HP). PIN lamamu tetap bisa dipakai dan otomatis ditingkatkan saat kamu membuka kunci.
- **Auto-backup Android dimatikan** supaya datamu tidak ikut tersalin ke cloud tanpa sepengetahuanmu. Gunakan Backup & Pulihkan di dalam aplikasi.

### 🛟 Data lebih aman
- **Cadangan otomatis harian** di HP, dengan tombol **Pulihkan cadangan otomatis** di Pengaturan → Backup & Pulihkan.
- **Hapus semua data dan pulihkan backup kini bisa dibatalkan**, karena data lama disalin dulu.
- **Pulihkan dari file lebih aman.** File backup yang rusak ditolak utuh, data lamamu tidak ikut setengah berubah.
- **Data yang gagal terbaca tidak lagi hilang diam-diam.** Salinannya diselamatkan.

### 🔧 Perbaikan
- **Halaman Tentang, Privasi, Ketentuan, dan Catat Cepat kini punya terjemahan Inggris lengkap.**
- **Transaksi berulang di tanggal 29-31** tidak lagi tercatat terlalu cepat.
- Pencatatan error internal diperbaiki untuk memudahkan pelacakan bug.

### 📲 Pilih APK
- **`-arm64.apk`**: untuk hampir semua HP Android modern ← **pilih ini**
- **`-universal.apk`**: untuk semua HP
