## Razarsa v2.0.0 🫙

Tampilan baru yang lebih sejuk dan ringan, bisa memakai fotomu sendiri, dan sekarang ada **versi Windows**. Semua data dan fitur v1.3.1 tetap sama.

### 🖥️ Windows (baru)
- Kerangka desktop: sidebar yang bisa diciutkan (Ctrl+B), bilah cari, dan halaman yang tampil di kolom tengah. Beranda dan Target memakai dua kolom.
- Pintasan: **Ctrl+1 … Ctrl+9** pindah halaman, **Ctrl+,** Pengaturan, **Ctrl+K** atau **Ctrl+N** palet perintah (cari halaman, cari transaksi, catat transaksi/tugas/agenda, ganti tema, kunci), **Ctrl+L** kunci, **Esc** tutup.
- Layar sambutan dua panel, PIN, catatan terkunci, backup berkata sandi, dan ekspor CSV sama seperti di HP.
- Data tersimpan di komputer itu saja. **Belum ada sinkron antar perangkat**; untuk memindahkan data, buat backup di satu perangkat lalu pulihkan di perangkat lain.
- Yang hanya ada di Android: pengingat/notifikasi dan "Cegah tangkapan layar" (barisnya disembunyikan di Windows). Sidik jari menjadi Windows Hello.
- File Windows belum ditandatangani digital: saat dibuka Windows bisa menampilkan peringatan SmartScreen ("Informasi lebih lanjut" → "Tetap jalankan").

### ✨ Baru di semua versi
- **Foto sendiri:** unggah foto profil dan foto sampul (Profil → Tampilan). Foto diperkecil dan dipotong otomatis, disimpan hanya di perangkat ini, tidak ikut backup.
- **Pakai latar:** latar ilustrasi kini pilihan. Bawaannya **polos** (abu kehijauan di mode terang, biru petrol di mode gelap). Nyalakan untuk Gurun Senja di Keuangan dan ruang kerja di Produktif. Efek kaca hanya muncul bila latar menyala.
- **Kurangi efek:** satu saklar di Pengaturan untuk mematikan blur dan animasi.
- **Menu bawah baru (HP):** bar kaca tipis dengan lekukan melingkar; bola aktif duduk pas di dalamnya.
- **Layar sambutan, buat PIN, dan kunci** dibuat ulang dari bentuk saja dan mengikuti tema terang/gelap.
- **Animasi isi:** angka menghitung naik, bar dan cincin terisi dari kosong, batang dan donat tumbuh saat halaman dibuka.
- **Pengaturan lebih rapi:** grup "Tampilan" dan "Produktif"; "Awal bulan anggaran" pindah ke Keuangan, "Awal minggu" ke Produktif, "Data" menjadi "Data dan cadangan".

### 🧹 Dirapikan
- Latar Langit dan semua maskot dihapus; keadaan kosong memakai lambang bentuk. Aplikasi lebih kecil.
- Data lama otomatis disesuaikan: latar **Gurun Senja** menjadi "Pakai latar" menyala, **Langit** menjadi polos.

### 📲 Unduh
- **Android:** `…-arm64.apk` (hampir semua HP modern) ← pilih ini, atau `…-universal.apk`.
- **Windows (64-bit):** `…-windows-x64.zip`. Ekstrak lalu jalankan `razarsa.exe`.
