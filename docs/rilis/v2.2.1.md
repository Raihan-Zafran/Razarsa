## Razarsa v2.2.1 🦕

Perbaikan dari hasil tes v2.2.0 di Windows dan HP.

### 🖥️ Windows
- **Menu aktif tidak lagi hilang** saat kursor di atasnya (dulu tulisan dan ikonnya tertutup warna krem).
- **Ciutkan menu lebih halus**: label memudar, halaman bergeser tanpa dihitung ulang setiap bingkai. Ikon di menu yang diciutkan tidak terpotong lagi.
- **Label Ctrl+1 … Ctrl+9 di menu dihapus** supaya tidak ramai; pintasannya muncul di tooltip saat kursor diam di atas menu.
- **Lebih ringan**: efek kaca buram dimatikan di Windows (bisa tertinggal aktif dari versi lama dan sangat berat), animasi masuk/keluar halaman tanpa skala, angka yang menghitung naik dan batang grafik tidak lagi menata ulang halaman setiap bingkai.
- Huruf teks biasa sedikit lebih tebal supaya tidak tipis dan buram di layar Windows; judul dialog kini tebal dan serasi.
- **Hapus aplikasi**: pemasang kini menawarkan menghapus data juga (transaksi, catatan, pengaturan, foto). Pilih "No" kalau ingin datanya tetap ada saat memasang ulang.

### 🐞 Perbaikan
- **Setor ke target**: nominal pakai titik ribuan, Enter langsung menyimpan, ada pilihan cepat (+50 rb, +100 rb, +500 rb, +1 jt), dan kalau nominal kosong ada pesannya (dulu dialog diam saja). Target baru dan ubah target juga pakai titik ribuan.
- **Foto profil tampil di kepala Beranda dan Hari ini** di HP (dulu selalu ikon orang).
- **Hapus permanen** kini juga menghapus profil, PIN, dan sidik jari / Windows Hello, lalu kembali ke layar buat profil. "Hapus, simpan cadangan" tetap menyimpan profil.
- HP: data tidak ikut cadangan Google maupun pindah HP otomatis, jadi menghapus aplikasi benar-benar menghapus datanya. Memasang APK baru di atas versi lama (tanpa hapus) tetap menyimpan data, itu normal.

### 📲 Unduh
- **Android:** `Razarsa-2.2.1.apk` (hampir semua HP modern), atau `Razarsa-2.2.1-universal.apk` (semua HP).
- **Windows (64-bit):** `Razarsa-2.2.1.exe` (pemasang), atau `Razarsa-2.2.1-portable.zip`.
