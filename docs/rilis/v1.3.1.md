- **Pengaturan:** nama palet yang panjang (misalnya "Zamrud & champagne") tidak lagi terpotong sebelum waktunya.
- Tes acak baru yang merusak file backup dan data tersimpan ribuan kali untuk memastikan aplikasi tetap terbuka dan datamu aman.
